# ClinPub 写作规范（3.0）

> 用途：阶段3 递进式写作的**唯一写作标准**，供 `writer-agent` 与 `writing` workflow 直接引用。
> 版本：随 ClinPub 3.0 引入
> 适用：临床研究原创论文（RCT / 队列 / 病例对照 / 横断面 / 描述性）

---

## 0. 来源与可信度说明

| 内容 | 来源 | 可信度 |
|---|---|---|
| 报告规范清单（STROBE / CONSORT / PRISMA） | EQUATOR Network、STROBE 官方站点 | **权威**（官方） |
| IMRAD 各节职责 | 学术写作通行规范 + 本项目既有约定 | 通行 |
| Discussion 结构 | Docherty & Smith, *BMJ* 1999（结构式讨论的经典论证）+ 现代框架 *From Findings to Meaning*（Learned Publishing） | 通行 + 较新 |
| 图表先行 / 反向写作 | 本项目 3.0 设计决定 + 一线写作实践 | **本项目约定** |
| 具体句式模板 | 本项目约定 | 本项目约定 |

> 凡是"本项目约定"的条目，是为了让 agent 有稳定产出；不代表学术界的唯一写法。

---

## 1. 总原则：事实层与解释层严格分离

这是全部写作规则的地基：

| 层 | 允许出现的地方 | 禁止出现的地方 |
|---|---|---|
| **事实**（做了什么、看到什么、统计量多少） | Results、Methods | — |
| **解释**（为什么这样、意味着什么、和谁一致） | Discussion、Introduction | **Results 一律禁止** |

Results 里写"两组差异显著，提示可能存在代偿机制"= 越界。正确写法只有："A 组 X 指标高于 B 组（β=…, 95%CI …, p=…）"。

---

## 2. 第 0 步：图表骨架（Figure Skeleton）

在任何正文之前，先把所有表与图排定，并为每一张写**一句大白话结论**。

```markdown
<!-- 05_Manuscript/FIGURE_SKELETON.md -->
| 序号 | 类型 | 标题（英文） | 一句话结论（中文） | 支撑的分析 |
|---|---|---|---|---|
| Table 1 | 基线表 | Baseline characteristics | 两组基线在年龄与病程上可比，用药剂量存在差异 | 基线比较 |
| Figure 1 | KM 曲线 | Survival by group | A 组 5 年生存率显著高于 B 组 | 生存分析 |
```

规则：

- **每张图必须有且只有一句话结论**，这句话将成为 Results 段落的主题句
- 图表顺序 = Results 叙述顺序 = 读者理解顺序（不是分析执行顺序）
- 一句话结论里**不许出现统计量**（统计量留给 Results）
- 图表清单按**研究类型 + 报告规范**生成，不套固定三件套：
  - RCT → CONSORT 流程图 + 主要终点表 + 安全性表
  - 队列/病例对照/横断面 → STROBE 参与者流程图 + 基线表 + 主要分析表 + （按需）生存/回归/敏感性
  - 描述性 → 基线表 + 分布/趋势图

## 3. Results

### 结构

一段对应一张图表，顺序与骨架完全一致。每段三段式：

1. **指路**：指出图表（但见下方禁忌）
2. **核心趋势**：主语 + 比较 + 方向 + 统计量
3. **必要细节**：样本量、缺失、亚组

### 句式模板

```
在 [分析人群] 中，[主要变量] 在 [A 组] 显著 [高/低] 于 [B 组]
（效应量 = …, 95%CI …, p = …）。
```

### 禁忌

- ❌ 段落开头用 "As shown in Table X" / "Table X shows"（已有 D-13 约定）
- ❌ 任何因果或机制解释
- ❌ 只报 p 值，不报效应量与置信区间
- ❌ 用 "显著" 描述未做多重比较校正的结果
- ❌ 把阴性结果藏起来（阴性结果同样要报统计量与 CI）

### 统计量报告格式（本项目强制）

| 类型 | 格式 |
|---|---|
| 连续变量组间比较 | 均值±SD 或 中位数(IQR)；差值/β + 95%CI + 精确 p |
| 分类变量 | n(%)；OR/RR + 95%CI |
| 生存 | HR + 95%CI；中位生存时间 |
| 相关 | r 或 ρ + 95%CI + p |
| 回归 | 每个协变量的 β/OR + 95%CI；模型整体拟合指标 |
| 多重比较 | 报校正后 p，并注明方法（FDR / Bonferroni） |

**p 值写法**：报精确值（`p = 0.032`），极小值写 `p < 0.001`；不写 `p = 0.000`。

## 4. Methods

### 三段式（遵循期刊惯例）

| 小节 | 内容 | 与分析的耦合 |
|---|---|---|
| **Participants / Study design** | 设计类型、入组/排除标准、招募时间地点、伦理批号与知情同意 | 无 |
| **Measures / Variables** | 评估工具（版本、信效度）、生物标志物或影像参数、主要与次要终点定义 | 弱（终点定义需与结果一致） |
| **Statistical Analysis** | 软件与版本、正态性检验、组间比较方法、协变量选择、缺失值处理、多重比较校正、敏感性分析 | **强：逐条对应实际执行** |

### "如实"的具体含义

Statistical Analysis 小节必须能逐条对上 `ANALYSIS_LOG.md`：

- 写"做了"的，日志里必须有
- 日志里做了的，这里必须写
- **计划但被否决的方法不写进 Methods**（可写进 Discussion 的局限性）
- 事后追加的分析要标明性质：`pre-specified` vs `post hoc / exploratory`

### 时态

- 写方法用**过去时**（"were enrolled"、"was performed"）
- 引用他人已确立的方法可用现在时（"Multiple imputation assumes that…"）

## 5. Discussion

### 结构：正金字塔，四段式（本项目采用）

> 经典结构式讨论（BMJ 1999）主张按小标题组织：主要发现 → 优势与局限 → 与文献比较 → 意义与展望。本项目将其压成四段，便于 agent 稳定产出。

| 段 | 内容 | 长度 |
|---|---|---|
| **1. 核心发现** | 3–4 句复述主要结果，**不重复统计量** | 短 |
| **2. 逐条解释** | 每个核心发现一段：重申 → 与既往比较（一致/矛盾）→ 机制解释 → 临床意义 | 占主体，每发现一段 |
| **3. 局限性** | 设计局限、样本、混杂、测量偏倚、外推性 | 1 段 |
| **4. 结论** | 2 句收尾，不再报数字 | 极短 |

### 每个发现的四步公式

```
① 重申：本研究发现 X。
② 对比：这与 [文献 A] 一致，但与 [文献 B] 不同。
③ 机制：可能因为 [神经生物学/心理病理/临床表型] 解释。
④ 意义：对 [筛查/诊断/干预] 的启示是 …
```

### 必须使用 `ANALYSIS_LOG`

Discussion 的信息来源不只是结果数字，还包括**分析过程**：

- 为什么选这个方法（而不是备选）
- 敏感性分析说了什么（稳健性）
- 哪些备选被否决、为什么（这往往就是最好的局限性素材）

### 常见局限性"菜单"（按研究类型选，不要全抄）

| 研究类型 | 高频局限 |
|---|---|
| 横断面 | 无法推断因果；反向因果可能 |
| 病例对照 | 选择偏倚、回忆偏倚 |
| 队列 | 失访偏倚、残余混杂 |
| 单中心/小样本 | 外推性受限、效能不足 |
| 用药人群 | 药物混杂（非首发未服药者） |
| 自评量表 | 回忆偏倚、社会期望偏倚 |
| 多终点 | 多重比较未校正或仅部分校正 |

### 禁忌

- ❌ 引入 Results 里没出现过的新结果
- ❌ 把局限性写成"本研究也存在一些局限性"这种空话（必须具体到本研究的哪个设计）
- ❌ 过度外推（横断面结果不得写成因果结论）

## 6. Conclusion 与 Abstract

**Conclusion**：2 句。第一句重申核心发现（不带数字），第二句给临床或研究启示。不与 Discussion 第 1 段重复措辞。

**Abstract**：全文完成后从各节摘句拼装，结构式四段：

| 段 | 取自 |
|---|---|
| Background | Introduction 第 2 段的 Gap |
| Methods | Methods 的 Statistical Analysis + Participants |
| Results | Results 的主要统计量（**必须带数字**） |
| Conclusions | Conclusion |

字数按目标期刊要求；未指定时 250–300 词。

**Title**：优先写"发现型标题"（点出结论方向），而非"描述型"（"A study of X"）。含研究设计或人群关键词，利于检索。

---

## 7. Introduction

### 结构：倒金字塔，3–4 段

| 段 | 内容 |
|---|---|
| **1. 临床背景** | 疾病负担、异质性 → 引出具体临床痛点 |
| **2. 已知与 Gap** | 前人做到哪 → **还缺什么**（Gap 必须能被本研究的实际分析填上） |
| **3. 本研究** | 纳入了谁、做了什么、**先验假设**是什么 |
| （4. 可选）一句话概述主要发现 | 部分期刊允许，需按目标期刊决定 |

### 叙事设计先行（本项目强制）

Introduction 从 `NARRATIVE.md` 展开，不从零硬写。叙事设计要回答：

1. **一句话卖点**：不是"我们研究了 X"，而是"我们发现了 Y，它改变了 Z 的理解"
2. **Gap 的精确表述**：现有研究缺的那一块，正好是本研究的分析覆盖的那一块
3. **叙事弧**：痛点 → 已知 → 未知 → 本研究
4. **目标读者与期刊调性**：决定语气与详略

### 禁忌

- ❌ 写成文献综述（逐篇罗列）
- ❌ Gap 与本研究实际分析不对应（**最严重**，审稿人一眼看出）
- ❌ 在第一段就报本研究结果
- ❌ 引用过多（默认 10–15 篇，与现有 `citation-strategy.md` 一致）

## 8. 报告规范对照（按研究类型）

| 研究类型 | 规范 | 官方来源 |
|---|---|---|
| 随机对照试验 | CONSORT 2010（+ 扩展） | [EQUATOR](https://www.equator-network.org/) |
| 队列 / 病例对照 / 横断面 | STROBE | [STROBE 官方清单](https://www.strobe-statement.org/checklists/) |
| 系统综述 / Meta | PRISMA 2020 | [EQUATOR](https://www.equator-network.org/) |
| 诊断准确性 | STARD | EQUATOR |

**用法**：写作前按研究类型拉取对应清单，逐项打钩；缺项要么补写，要么在局限性里说明理由。

## 9. 语言与风格

| 项 | 规则 |
|---|---|
| 语种 | 正文中文，图表与图注英文（沿用现有约定） |
| 时态 | Results/Methods 过去时；Discussion 中既有事实过去时、普遍规律现在时 |
| 语态 | 方法可用被动；主张与解释优先主动 |
| 数字 | 统计量统一格式；单位与小数点位数全文一致 |
| 缩写 | 首次出现给全称，此后统一 |
| AI 味 | 禁用 "值得注意的是""综上所述""随着…的不断发展" 等空转句；禁止三项并列排比堆砌 |
| 引用 | Vancouver，全部带 DOI |

## 10. 交付前一致性检查（拼装前强制）

| # | 检查项 | 不通过的后果 |
|---|---|---|
| 1 | 每个 Results 段落都能对上骨架里的一张图表 | 补写或删段 |
| 2 | Methods 的 Statistical Analysis 与 `ANALYSIS_LOG` **双向**一致 | 补写或删方法 |
| 3 | Introduction 的每个假设都能在 Results 找到对应分析 | 改 Gap 或补分析 |
| 4 | Discussion 不引入新结果 | 移回 Results 或删除 |
| 5 | 变量名/方法名全文一致（以 `project_config.yml` 为真源） | 统一 |
| 6 | 图表编号连续、正文引用与图注一一对应 | 重编号 |
| 7 | 所有统计量都有效应量 + 95%CI + 精确 p | 补算 |
| 8 | 报告规范清单无缺项（或缺项已在局限性说明） | 补齐 |
| 9 | 摘要数字与正文一致 | 同步 |
| 10 | 引用全部有 DOI，且正文引用与文献表一一对应 | 补全 |

## 图表交付检查清单

> 出图后逐项过。不通过的不许进 `05_Manuscript/`。

### 物理与格式

- [ ] 画布宽度 = 目标期刊栏宽（Nature 89 / 183 mm），由 `quality.style` 决定
- [ ] 主图导出 **pdf + svg**（矢量）；tiff 只用于补充材料（300 dpi）
- [ ] 字体 Arial，全部文字落在 **5–7 pt**
- [ ] 文字可编辑（SVG 保留 `<text>`，PDF 内嵌 TrueType），未转曲

### 内容与标注

- [ ] 每张图有唯一结论，与 Results 段落一一对应
- [ ] 坐标轴标题写的是什么（单位/量表名），不是变量名 `post_score`
- [ ] 统计量齐全：效应量 + 95%CI + 精确 p（禁 `p = 0.000`）
- [ ] 每组样本量 n 已标（图上或图注）
- [ ] 图例不重复坐标轴已表达的信息（两组比较通常不需要图例）
- [ ] 没有同一统计量画两遍（箱线图已含中位线）

### 一致性

- [ ] 同篇文章所有图共用同一风格包（线宽/字号/配色一致）
- [ ] 图表编号按正文首次出现顺序
- [ ] 图注自足：不看正文也能读懂这张图
