# 方法说明 — 01_BaselineTable

## 分析目的

描述研究样本的基线特征，并按 `group`（Control / Treatment）比较两组是否均衡。
探索性研究中此表同时用于**判断"分组变量本身是否携带信息"**。

## 数据与变量

- 输入：`02_PreprocessedData/data/cleaned.csv`（N = 102，完整病例）
- 连续变量：`age`、`bmi`、`baseline_score`、`post_score`、`egfr` → 均值 (SD)
- 分类变量：`sex`、`comorbidity` → n (%)，`comorbidity` 参照 `None`

## 方法与参数

| 项 | 内容 |
|---|---|
| 软件 | R 4.4.3 |
| 连续变量检验 | 两样本 t 检验（未假设方差齐，Welch） |
| 分类变量检验 | Pearson χ² |
| 效应量 | 连续：标准化均值差 SMD；分类：仅列分布 |
| 显著性水平 | α = 0.05（未做多重比较校正，本表为描述性） |

## 输出结果

| 变量 | Control (n=48) | Treatment (n=54) | P | SMD |
|---|---|---|---|---|
| age | 56.0 (11.3) | 58.1 (10.0) | 0.347 | 0.19 |
| bmi | 23.8 (3.4) | 24.3 (3.7) | 0.432 | 0.16 |
| baseline_score | 49.6 (12.4) | 50.1 (14.8) | 0.840 | 0.04 |
| **post_score** | **46.6 (15.1)** | **37.5 (17.3)** | **0.005** | **-0.56** |
| egfr | 89.8 (14.6) | 93.1 (14.5) | 0.255 | 0.23 |
| sex (Female) | 28 (58.3%) | 30 (55.6%) | 0.934 | — |
| comorbidity None | 15 (31.2%) | 17 (31.5%) | 0.216 | — |
| comorbidity Hypertension | 17 (35.4%) | 11 (20.4%) | | |
| comorbidity Diabetes | 10 (20.8%) | 12 (22.2%) | | |
| comorbidity Both | 6 (12.5%) | 14 (25.9%) | | |

**关键观察**：`baseline_score` 两组几乎完全一致（SMD 0.04）——符合随机化预期；
`post_score` 是唯一出现组间差异的变量（SMD -0.56，中等效应）。

## 假设与偏倚

- t 检验假设近似正态；`age` / `bmi` / `egfr` / 两评分在两组内均近似对称（见 fig 1A）。
- 未对多重比较校正：本表为描述性，不用于确证性推断。
- 完整病例分析（N=102）隐含"完全随机缺失"假设；缺失机制未验证。
