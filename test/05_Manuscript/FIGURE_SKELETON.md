# 图表骨架（FIGURE_SKELETON）

> 写作的定海神针。**顺序 = Results 叙述顺序 = 读者理解顺序**（不是分析执行顺序）。
> 每张图配一句**不含统计量**的结论——连起来应该就是一个完整故事。

## 故事线自检

把下面五句结论连起来读：

1. 两组在治疗前的症状严重程度相当，人口学与体型特征也接近。
2. 在四个候选指标中，只有治疗后的症状评分在两组间表现出差异。
3. 这一差异在调整年龄、性别与体型之后依然存在。
4. 换用非参数方法与多重插补后，结论没有改变。
5. 肾功能与分组无关，不能解释症状评分的差异。

→ **故事成立**：基线可比 → 发现差异 → 排除混淆 → 稳健 → 排除替代解释。
