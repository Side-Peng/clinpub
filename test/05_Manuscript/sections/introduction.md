# Introduction

症状负担是这类患者最直接影响生活质量的临床问题之一。症状评分的轻微变化，往往对应着睡眠、日常活动能力与照护负担的实质差别。{{cite:Vyas2020,Triolo2024}}正因如此，临床医生在为具体患者决定是否启动治疗时，最想知道的不是"平均而言治疗有效吗"，而是"像我面前这位患者一样的人，治疗后会更好吗"。这个问题的答案取决于两个前提：治疗确实改变了症状轨迹，以及接受治疗者与未接受治疗者本来是可以比较的。

随机对照试验为第一个前提提供了最好的证据。但随机试验的人群经过严格筛选，合并症少、依从性高，与真实临床环境中的患者存在系统性差异。{{cite:Steffens2026}}在真实世界中，是否接受治疗本身就是一个复杂的决策结果——症状更重的人更可能被治疗，而症状更重恰恰预示着更差的结局。这种"适应证混杂"使得直接比较治疗组与未治疗组的观察性研究极易得出偏倚的方向。{{cite:Lee2022,Remschmidt2015}}因此，真实世界数据能否在**剔除可测混杂之后**仍然显示组间差异，是判断观察性证据价值的关键一步。

本研究利用一份横断面临床样本回答这一问题。我们首先检验两组在治疗前的症状严重程度上是否可比，以此为后续比较提供可验证的均衡性证据；随后在调整年龄、性别与体质指数后估计组间差异；最后通过非参数检验与多重插补检验结论的稳健性。我们的先验假设是：若治疗状态与更低的症状负担相关，那么这一差异应当在治疗前评分可比的前提下依然存在，并且不应随缺失处理方式或分布假设而改变。需要指出的是，本研究的结局指标系在比较候选指标后确定，全部推断均按探索性结果处理。
