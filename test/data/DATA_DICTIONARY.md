# 测试数据说明

> 合成数据，**不含任何真实患者信息**。固定随机种子，可复现。

## 文件

`patients.csv` —— 120 例，11 列，宽表（一行一患者）。

## 变量字典

| 变量 | 类型 | 说明 | 缺失 |
|---|---|---|---|
| `patient_id` | 整数 | 患者编号（1–120） | 无 |
| `age` | 整数 | 年龄（岁），28–85 | 无 |
| `sex` | 分类 | Male / Female | 无 |
| `bmi` | 连续 | 体质指数 | ~8% |
| `group` | 分类 | **Treatment / Control**（干预分组，交替分配） | 无 |
| `baseline_score` | 整数 | 基线症状评分（0–100，越高越重） | ~8% |
| `post_score` | 整数 | 干预后症状评分（0–100） | 无 |
| `followup_months` | 整数 | 随访月数（6–60） | 无 |
| `event` | 二分类 | 结局事件（1=发生，0=删失） | 无 |
| `comorbidity` | 分类 | None / Hypertension / Diabetes / Both | 无 |
| `egfr` | 连续 | 估算肾小球滤过率 | ~8% |

## 数据里预埋的特征（用于验证分析与写作是否"如实"）

1. **干预效应**：`Treatment` 组 `post_score` 平均比 `Control` 低约 6.5 分 → 组间比较应显著
2. **年龄混杂**：`age` 对 `post_score` 有正相关（年龄越大评分越高）→ 多因素调整后干预效应应缩小
3. **生存信号**：`Treatment` 组事件风险略低；`age` 与 `comorbidity=Both` 提高风险
4. **缺失**：`bmi` / `baseline_score` / `egfr` 各约 8% 缺失 → 触发缺失处理策略讨论（MICE 或完整病例）
5. **非线性可能**：`egfr` 与结局关系偏弱，可作为"是否值得做 RCS"的判断点

> 这些特征**故意不写在项目配置里**——初始化阶段应通过与用户讨论得出，
> 而不是从数据字典里抄。测试时请扮演"只有数据、没有结论"的研究者。
